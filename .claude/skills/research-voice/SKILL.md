# Research voice

Casual authority on a C1 exhibit. The reader can reconstruct the check.
`rch-editor` owns ethos, scene, spoken host, gist, closer. This skill owns
claim-size, query direction, and lab cadence. `I` and `we` are both fine.

On an rch-editor post this is a review lens, not a second structure.

## Common Mistakes

- Re-running `rch-editor`. Do not flag ethos-first, named host, subjunctive C1
  scenes, delayed mechanism, unique closer, gist rules, `wrap`/vaulting, Alice
  Bob Eve, or dashboard excerpt. Those are the other persona.
- Requiring team-only `we`, a lab byline, BibTeX, a next-experiments list, or
  session-count TL;DR on a C1 series post.
- Launch copy in the lede: "until now," Get started today, "this post will
  discuss," AI summary bullets, product-stack tour (identity records, access
  reviews, support path) that is not this post's object. `c1-brand-voice` is
  a different channel.
- Calling emptiness of a difference a proof of all of C1, every grant path,
  or every connector. Size the claim to the check on the page.
- Treating a fact you encoded (URI names a subtree; a connector file can send
  any body; CEL that does not see the JSON) as something the analysis
  discovered.
- Asking "is this grant safe?" The question is whether the candidate allows an
  assignment the reference (Access Profile, IdP-signed statements, session
  policy) does not. Extra Role representable / difference empty / residual.
- Landing on another person or model squinting at a list. The standing move is
  C1's check: Classifiers, a closed class, a Grants row C1 refuses.
- Hiding the exhibit. A listing, table, CEL, or PairLedger belongs in the body,
  not only in a resource list.
- Inventing counts or latencies. If the run is not in hand, do not write the
  table.
- Numbers with no exclusion (what the clock includes, what it does not).
- Inverting the formal object: English first, then vocabulary that sounds like
  a check. Formula, table, or JSON first; gloss after.
- `Background` / `Discussion` as headings. Section titles are jobs or claims,
  and they still have to progress (`rch-editor` rule 10).
- Excitement as a refrain. One close, aimed at this post's after-states.
- A C1 outage in the indicative. Exhibit listings may be present tense;
  production failures stay subjunctive (`rch-editor`).
- Session Match residuates. Production Match fills missing `source_ip` as empty strings and returns `(false, nil)`. Residual unfinished membership is the analysis of the classifier, not the live eval. Say which.
- Naming an as-yet-unfixed defect in C1 production. Surface that to the
  author. Public copy uses the class and a constructed exhibit.

## Persona

A named C1 engineer walking a check other builders have seen in a class and
have not run on a live Access Profile, session policy, vault epoch, or
connector file. Direct address is fine. Prior work is one named paper or
cousin, not a resume.

Tone: short punch after a real exhibit (`Clever.`). "Let's try this query on
the listing." A reviewer fooled by a contradictory proposal, while C1 still
refuses the Grants row, is a result. Adjacent work is a peer with a link.
Speak in the light of the public discourse: spec, published measurements,
the conversation at scale. One link to introduce a background language
(Datalog). Do not stack academic Datalog citations next to Krohn-Rhodes.

## Review (rch-editor draft)

One axis. Quote the claim and the exhibit. Do not rewrite the walk.

Flag:

1. Claim wider than the check (platform-proof, every grant, every connector).
2. Encoded HOW presented as a discovery.
3. Query inverted ("safe" vs extra assignment representable).
4. Residual treated as empty, or unknown treated as pass.
5. Missing exhibit, or exhibit only at the end.
6. Launch CTA or brand-stack lede.
6b. Disclaimer the owner did not ask for (`This surface is a prototype`). CS term before the C1 job. This post's surface with no reason it is on the page.
7. Numbers without exclusions.
8. Judge-as-landing (human or model) where Classifiers / closed class / refused
   Grants row should sit.
9. Allusion without a receipt (`the public conversation`, `at scale` with no
   dated post or measured table in that beat).
10. A vendor defect that is not in a public record. Cloudflare's published
    2,594-tool count is a size measurement. It is not a missed-`if` on `/admin`.

Do not flag `I` vs `we`. Do not demand a lab close. Do not move ethos.

## Write (inside rch-editor)

Follow `rch-editor` whole-piece. Apply this cadence on the walk:

- Teach the query before the listing: candidate minus reference, not "safe."
- Name the C1 surface that is the check (Access Profile, session policy,
  vaulting epoch, dynamic-group CEL, connector runtime file).
- Name the C1 surface on the dashboard if the post names a feature.
- Scope once: relative to this encoding and this model of the source. Residual
  fails closed. Do not volunteer prototype vs production unless the owner asked.
- Map a path the check cannot see to the object this post owns (unsigned first
  Assertion; a Role Okta never assigned; a connector grant the review did not
  name). Do not import a sibling post's object.

## C1 objects

The check that sits outside the IdP, the connector, and the reviewer is C1:
the review of all current state, the Grants row that does not land,
Classifiers as membership.

| Lab move | C1 object |
| --- | --- |
| Maximum / reference policy | Access Profile; IdP-signed statements |
| Candidate exceeds maximum | Extra Role, extra CEL path, extra grant |
| Difference empty | Closed class; emptiness of a difference |
| Unknown / residual | Do not certify; fail closed |
| Path the proxy cannot see | Signature wrapping story; connector body the policy does not read |
| Fixed tool, not a full SDK | One connector runtime file, one CEL path, one session policy |
| Check before the effect | Check before the grant lands |
| Named platform | The dashboard feature this post shows |
| Harness repo | The exhibit on the page; gist file after pull |

## Before finishing

- Did not overturn `rch-editor` structure, host, gist, or subjunctive C1 scenes
- Claim matches the check; residual and encoding scope are explicit
- Exhibit is in the body; numbers have exclusions; formula/table then gloss
- No launch CTA in the lede; no excitement refrain; `I` or `we` both allowed
- Review output quotes claim vs exhibit; it does not restyle the ethos
