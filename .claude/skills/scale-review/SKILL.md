# Scale review

A fix for halted rhythm that mints a void referent is not done. Present only after a second pass at every grain.

## Common Mistakes

- Fixing one TONE number and handing the file over. The changed sentences are where the next defect lands.
- Parent doing every grain. Spawn at least: post outline (`information-flow`), per-H2 reconstruction (`prose-clarity`), sentence/referent audit (TONE 80–89), humanizer.
- Re-running only the persona that just fired. After a TONE 89 fix, run 81, 88, 65, humanizer on those sentences.
- Opening HTML before the second pass.

## Grains (all, in order)

1. Post: conceptual-progress outline. Ethos, product as one object, exhibit before reference.
2. Section/paragraph: reconstruction. Fact vs example, one topic, sentence order.
3. Two-to-three sentences: both sides of a comparison; `this`/`that`/`those` + noun; agentless passive; generic role-pairs; `Name means`; category named before instance; each jargon noun already in the reader's inventory (TONE 93).
4. Word: `it` for a technical object; `machine` for a table; `you`; empty `This is ___`.
5. Humanizer: not-X-but-Y, tour-guide, one-line closer, same-opening run.

## Pass

Rewrite from grain-2 and grain-3 findings. Then re-run grains 3–5 on the changed sentences only. If a new defect of a different class appears, fix and re-run those grains again. Stop when the second pass is clean. Then humanizer, rebuild `read.html`, open HTML only.

## Before finishing

- At least one subagent ran at post grain and one at section grain
- Changed sentences were re-audited for other defect classes
- HTML opened only after that second pass
